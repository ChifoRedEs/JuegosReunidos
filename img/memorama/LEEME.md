# Imágenes del Memorama

Cada carpeta es un tema (`animales`, `banderas`, `comida`, `naturaleza`, `transportes`, `lugares`, `deportes`, `musica`, `objetos`, `ropa`, `caras`, `fiestas`) más `frutas`.
Cada una tiene sus `.webp` de 128×128 y un `nombres.json` con el nombre en español. Tras añadir o quitar imágenes: `python tools/generar_memorama.py && python tools/generar_sw.py`.
